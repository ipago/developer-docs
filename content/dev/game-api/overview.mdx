The **Game API** is the integration your game server, plugin, or bot uses to
**deliver purchases in-game** and report back. Where the
[Developer API](/dev/developer-api/overview) is for managing your store, the
Game API is the runtime side that runs on (or next to) your server.

## What it's for

- **Fetch pending deliveries** for your server, the items players bought that
  still need to be granted.
- **Run the delivery** (give the rank, currency, crate, or run a command).
- **Confirm completion** so 2Pay marks the order delivered.

## Typical flow

1. A player buys on your Webstore or embedded Checkout.
2. Your server learns about it, either from a `delivery.pending`
   [webhook](/dev/webhooks/overview) or by polling pending deliveries.
3. Your plugin grants the item in-game.
4. Your server confirms delivery, and 2Pay marks it complete.

## Authentication

The Game API authenticates with a **server token** scoped to a single store, so
you can safely ship it inside a plugin or run it on your game host.

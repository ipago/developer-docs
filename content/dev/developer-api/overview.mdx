The **Developer API** is 2Pay's **headless API**: a management and communication
layer for the products you already have in your store.

## What it's for

- **Manage your products** that live in your store.
- **Track delivery** of purchases, see what has been delivered and what has
  not.
- **React to events** so your systems stay in sync with 2Pay.

## What it is not

The Developer API is **not** a way to define custom, one-off products on the fly.
Products are always created and managed in the admin panel at **app.2pay.gg**;
the API works with those existing products.

<Callout type="info">
  If you've used Tebex, this is **not** the same as their "Checkout API" for
  building ad-hoc custom products. We deliberately keep product definition in the
  panel for now.
</Callout>

## Conventions

The API is resource-oriented, returns JSON, and authenticates with API keys.

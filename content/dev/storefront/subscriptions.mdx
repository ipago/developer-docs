---
title: Storefront subscriptions
description: Start a recurring subscription for a buyer from the storefront.
---

For recurring products (memberships, monthly perks), start a subscription rather
than a one-off basket:

```bash
curl -X POST https://api.2pay.gg/v1/storefront/myshop/subscribe \
  -H "Idempotency-Key: <uuid>" \
  -H "Content-Type: application/json" \
  -d '{ "product": "prod_sub_123", "quantity": 1, "game_username": "Steve",
        "return_url": "https://yourgame.example/thanks" }'
```

Like checkout, this returns a `client_secret` for the embedded flow. Once the
first invoice is paid you receive a `subscription.created` event, and each renewal
emits `subscription.renewed`. Resolve the subscription after return with
`GET /v1/storefront/{slug}/subscriptions/by-session/{sessionId}`.

<Callout type="info">
  Renewals are billed automatically by 2Pay. React to `subscription.renewed` to
  extend access, and to `subscription.canceled` to revoke it.
</Callout>

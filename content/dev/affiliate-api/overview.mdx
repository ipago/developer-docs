<Callout type="warn">
  **Planned, not available yet.** There is no Affiliate API today: no affiliate,
  referral endpoints, no affiliate scopes for API keys, and no
  affiliate webhook events. Nothing on this page can be called.
</Callout>

The planned **Affiliate API** would let you run a referral program on top of your
store, so creators, streamers, and partners earn a share of the sales they bring
in. The idea:

- you register affiliates and give each one a referral code or link,
- iPago attributes the orders that come in through that code to the affiliate,
- you read what each affiliate earned.

Endpoints, fields, and rules are not designed yet, so they are not documented
here. When the feature ships it will follow the same
[conventions](/dev/developer-api/conventions) as the rest of the Developer API.

Until then, giving each partner their own
[coupon](/creators/your-store/gift-cards-and-coupons) code lets you count how
often each partner's code is used.

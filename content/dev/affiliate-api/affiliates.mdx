---
title: Affiliates
description: Create, list, fetch, and deactivate the partners promoting your store.
---

<Callout type="warn">Preview: the Affiliate API is a planned feature and is not available yet. The endpoints described here are not callable today.</Callout>

An **affiliate** is a partner who promotes your store in exchange for a commission
on the sales they drive. Each affiliate has a unique **referral code** that ties
purchases back to them.

## The affiliate object

```json
{
  "object": "affiliate",
  "id": "aff_01HA0...",
  "name": "Alex Streams",
  "email": "alex@example.com",
  "code": "ALEX",
  "active": true,
  "stats": {
    "referrals": 142,
    "earned": { "amount": 38200, "currency": "eur" }
  },
  "created": "2026-04-11T09:00:00Z"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Affiliate id (`aff_`). |
| `name` | string | Display name of the partner. |
| `email` | string \| null | Contact email. |
| `code` | string | The referral code buyers use. Unique within your store. |
| `active` | boolean | Whether new purchases can be attributed to them. |
| `stats.referrals` | integer | Lifetime count of attributed orders. |
| `stats.earned` | object | Lifetime commission as [money](/dev/developer-api/conventions#money). |
| `created` | string | When the affiliate was created. |

## Create an affiliate

```
POST /v1/affiliates
```

```bash
curl https://api.2pay.io/v1/affiliates \
  -H "Authorization: Bearer sk_live_..." \
  -H "Idempotency-Key: $(uuidgen)" \
  -d "name=Alex Streams" \
  -d "email=alex@example.com" \
  -d "code=ALEX"
```

| Parameter | Required | Description |
| --- | --- | --- |
| `name` | yes | Display name. |
| `code` | no | Desired referral code. Omit to have one generated. Must be unique. |
| `email` | no | Contact email. |

A `409` is returned if the `code` is already taken; pick another.

The affiliate's referral link is simply your store URL with the code attached, for
example `https://yourstore.2pay.gg/?ref=ALEX`. Share either the link or the bare
code.

## List affiliates

```
GET /v1/affiliates
```

| Parameter | Description |
| --- | --- |
| `active` | `true` / `false` filter. |
| `code` | Look up by exact code. |
| `limit`, `starting_after`, `ending_before` | [Pagination](/dev/developer-api/conventions#pagination). |

```bash
curl "https://api.2pay.io/v1/affiliates?active=true" \
  -H "Authorization: Bearer sk_live_..."
```

## Retrieve an affiliate

```
GET /v1/affiliates/{id}
```

## Deactivate an affiliate

Deactivating stops **new** attributions without deleting history; existing
referrals and commissions are preserved.

```
POST /v1/affiliates/{id}/deactivate
```

```bash
curl -X POST https://api.2pay.io/v1/affiliates/aff_01HA0.../deactivate \
  -H "Authorization: Bearer sk_live_..." \
  -H "Idempotency-Key: $(uuidgen)"
```

Re-enable with `POST /v1/affiliates/{id}/activate`.

<Callout type="info">
  To see what an affiliate has driven, read their
  [referrals and commissions](/dev/affiliate-api/referrals-and-commissions),
  filtered by `affiliate={id}`.
</Callout>

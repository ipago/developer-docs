## Poll the queue

```http
GET https://game.ipago.io/v1/queue
```

**Auth:** game server token in the `X-iPago-Server-Token` header. See [authentication](/dev/reference#authentication).

**Operation ID:** `pollQueue`

**Headers**

| Name | Type | Required | Notes |
| --- | --- | --- | --- |
| `X-iPago-Server-Token` | `string` | Yes | Server token: the game server's token. |

**Response** `200`

| `object` | `string` | Yes | Always `queue`. |

## Confirm executed commands

**Operation ID:** `confirmQueueCommands`

**Headers**

| Name | Type | Required | Notes |

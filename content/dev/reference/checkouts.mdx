## Create a checkout

```http
POST https://api.ipago.io/v1/checkouts
```

A test-mode key creates a test-mode checkout, paid through the store's separate test payment credentials.

**Auth:** API key as a bearer token, scope `checkouts:write`. See [authentication](/dev/reference#authentication).

**Operation ID:** `createCheckout`

**Headers**

| Name | Type | Required | Notes |
| --- | --- | --- | --- |
| `Authorization` | `string` | Yes | API key: Bearer sk_live_... or sk_test_.... |
| `Idempotency-Key` | `string` | No | A unique key per logical request. Retrying with the same key replays the first response instead of acting twice. |

Required when any item does; iPago grants the roles to this account once the order is paid. For a subscription it is kept for every renewal. Link the account yourself (OAuth2 scope identify) so the id is really the buyer's. |

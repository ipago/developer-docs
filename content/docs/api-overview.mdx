The 2Pay API is resource-oriented, returns JSON, and uses standard HTTP verbs.
It is the source of truth that every 2Pay surface is built on.

## Conventions

- Base URL: `https://api.2pay.io/v1`
- Auth: Bearer API keys (`sk_live_` / `pk_live_`, restricted keys)
- Idempotency: send an `Idempotency-Key` header on writes
- Pagination: cursor based (`limit`, `starting_after`)
- Webhooks: signed events you subscribe to

## Core resources

`product`, `basket`, `checkout_session`, `order`, `customer`, `subscription`,
`refund`, `payout`, `payment_method`, `event`, and `webhook_endpoint`.

```bash
curl https://api.2pay.io/v1/checkout/sessions \
  -H "Authorization: Bearer sk_live_..." \
  -H "Idempotency-Key: 7b9c1f2a" \
  -d basket=bsk_1a2b3c \
  -d mode=embedded
```

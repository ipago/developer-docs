The **Affiliate API** lets you run a referral program on top of your store:
reward creators and partners for the sales they drive.

## What it's for

- **Manage affiliates**, create and list the partners promoting your store.
- **Track referrals**, attribute orders to an affiliate via referral codes or
  links.
- **See commissions**, read what each affiliate has earned per sale.

## How it fits together

1. You create an affiliate and share their referral code or link.
2. When a referred buyer purchases, 2Pay attributes the order to that affiliate.
3. The earned commission is recorded and available through the API and in
   **app.2pay.gg**.

<Callout type="info">
  Commission rates and payout rules are configured in the admin panel. The API
  is read-and-manage on top of that configuration.
</Callout>

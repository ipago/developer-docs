2Pay has a single plan today. There are no paid tiers and no trials: every store
gets the same features and pays the same [fees](/creators/pricing/fees-billing).

## Included in every store

| Feature | Included |
| --- | :---: |
| Hosted webstore on a `{slug}.2pay.gg` subdomain | ✓ |
| Three layout themes, light or dark appearance, accent colour, and logo | ✓ |
| Card, PayPal, Klarna, BLIK, Przelewy24, iDEAL, Bancontact, and Link | ✓ |
| One-off packages and monthly or yearly subscriptions | ✓ |
| Sales, coupons, and gift cards | ✓ |
| Automatic in-game delivery | ✓ |
| Statistics | ✓ |
| Developer API and webhooks | ✓ |
| Team members with owner, admin, and member roles | ✓ |
| VAT handled as Merchant of Record | ✓ |

## Not available yet

- A custom domain for your webstore.
- Custom webstore templates, CSS, and scripts.
- An affiliate or referral program.

The [platform fee](/creators/pricing/fees-billing#platform-fee) is stored per
store, so a different rate can be agreed for high volume.
[Talk to us](mailto:support@2pay.gg) if that applies to you.

title: Plans
description: What every iPago store includes, and what is not available yet.
---

iPago has a single plan today. There are no paid tiers and no trials: every store
gets the same features. iPago's margin and the card cost are on
[Margin & card cost](/creators/pricing/fees-billing).

## Included in every store

| Feature | Included |
| --- | :---: |
| Hosted webstore on a `{slug}.ipago.io` subdomain | ✓ |
| Three layout themes, light or dark appearance, accent colour, and logo | ✓ |
| Card, PayPal, Klarna, BLIK, Przelewy24, iDEAL, Bancontact, and Link | ✓ |
| One-off packages and monthly or yearly subscriptions | ✓ |
| Sales, coupons, and gift cards | ✓ |
| Automatic in-game delivery | ✓ |
| Statistics | ✓ |
| Developer API and webhooks | ✓ |
| Team members with owner, admin, and member roles | ✓ |
| iPago sells to the player and handles VAT on that sale | ✓ |
| Weekly purchase invoice, paid by the invoice due date | ✓ |

## Not available yet

- A custom domain for your webstore.
- Custom webstore templates, CSS, and scripts.
- An affiliate or referral program.

The [margin](/creators/pricing/fees-billing#margin) is stored per store, so a
different rate can be agreed for high volume.
[Talk to us](mailto:support@ipago.io) if that applies to you.
